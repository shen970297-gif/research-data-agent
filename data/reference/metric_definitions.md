# 定量指标说明

> 本文件用于科研数据分析 Agent 的 RAG 演示，不构成临床结论或正式实验规范。

## AUC

AUC 表示在指定时间窗内，信号强度随时间累积的总暴露量。
在动态示踪数据中，可用于比较不同组别或不同 ROI 的整体信号变化。

## Tmax

Tmax 表示信号达到最大值的时间点。
Tmax 提前或延后只能描述动力学变化，不能单独推断具体生物学机制。

## Cmax

Cmax 表示指定时间窗内观测到的最高信号强度。

## 清除半衰期

清除半衰期用于描述信号下降到初始参考水平一半所需的时间。
计算时应统一采样时间点、拟合模型和数据清洗规则。
